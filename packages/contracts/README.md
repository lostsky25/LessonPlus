# @lessonplus/contracts

Внешние контракты монорепозитория: конверт события, каталог имён событий и DTO статуса системы для интерфейса.

Доменные модели сервисов сюда не переносятся. Поля `payload` бизнес-событий в TypeScript не заданы. Проектируемые HTTP-операции описаны в [openapi/README.md](openapi/README.md) и контроллеров не добавляют.
