# PostgreSQL

Один экземпляр PostgreSQL и база `lessonplus`. Скрипт `init/001-roles.sh` при первом создании тома создаёт пять схем и пять ролей. Каждая роль владеет только своей схемой, не является суперпользователем и не получает права на чужие схемы.

Бизнес-сервисы подключаются своими ролями. Учётная запись `POSTGRES_USER` нужна только контейнеру для инициализации.
