# notifications

Сервис уведомлений и результатов доставки. На этом этапе подняты процесс, своя схема PostgreSQL, подключение к RabbitMQ и технические таблицы outbox. Отправка сообщений не реализована.

Бизнес-сценарии и публикация событий не реализованы. Границы слоёв описаны в `src/*/README.md` и в `docs/architecture.md`.
