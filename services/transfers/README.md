# transfers

Сервис заявок и правил переноса. На этом этапе подняты процесс, своя схема PostgreSQL, подключение к RabbitMQ и технические таблицы outbox. Saga переноса не реализована.

Бизнес-сценарии и публикация событий не реализованы. Границы слоёв описаны в `src/*/README.md` и в `docs/architecture.md`.
